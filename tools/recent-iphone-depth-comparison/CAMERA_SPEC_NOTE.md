# What the 17/18 camera specifications establish

Primary Apple specifications distinguish the main cameras: [iPhone 17 Pro](https://support.apple.com/en-us/125090) lists a fixed f/1.78 main-camera aperture; [iPhone 18 Pro](https://www.apple.com/iphone-18-pro/specs/) lists a variable-aperture main camera. Thus the **whole camera systems are not identical**.

Both specifications list a LiDAR scanner without establishing a sensor-module part number or module identity. We have **not verified whether the 17 and 18 use identical LiDAR hardware**. A change to the RGB camera, processor, aperture or memory is not evidence of better LiDAR depth accuracy. This packet measures a publisher-labeled 17 Pro recording, not an 18 Pro recording, and contains no controlled cross-generation hardware-accuracy experiment.

These are specification facts and an explicit evidence limit, not an inferred teardown result. Source review date: 2026-10-26.
