## Reproducibility boundary

`verify_packet.py` is new, separately identified packaging-validation code. It checks the supplied hashes and reconciles saved-array counts without executing the native experiment. Its success is not a fresh native replay, sensor accuracy check or navigation pass.

The executed `audit_selected.py`, decoder-support scripts and `native/run_native_audit.py` are preserved for source review, **not advertised as turnkey scripts in this new directory layout**. In particular, the native driver's four frozen field/manifest hashes include the original absolute-path bytes in two manifests. Normalized manifests intentionally fail those original-byte gates. The decoder-support scripts also expect the original audit layout and decoder binary. The original large archives and compiled dependencies are not supplied here.

A portable native replay requires a distinct reviewed source/input-normalization cut, original archive acquisition or explicit selected-fixture input contract, matching compiler/dependencies, new source/input pins and a new bounded execution receipt. Do not disable the original gates, relabel public copies as the exact original inputs, or call such a future run the historical run. No such replay, download, decoder rebuild or dependency installation occurred while preparing this packet.
