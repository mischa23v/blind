# Room-loop planner, support-classifier and candidate mesh-bridge checkpoints

**No complete table lap or physical-device navigation is established by this packet.** The separate assisted doorway round trip is published at commit7ff6d47. All results here preserve failures and uncertainty.

## Outcomes

- Stage50: fixed source loop could not start because one tiny floor triangle failed the training-normal gate before local recovery could run. No movement.
- Stage52: ordering-only correction retained the original5-degree training /45-degree raw-normal /2mm residual rules; all five fixed support memberships admitted. Exact arrays and receipts are included.
- Stage53: original shortest native route moved3.640m and reached one goal; a support membership rejection stopped the next movement. Zero laps.
- Stage55: source-only clearance-weighted native grid proposes22.078m loop, but unchanged follower would require7,960 ticks versus2,500 budget. This raw proposal was not executed as a full-body trial.
- Stage56: source-only LOS simplification retains sampled minimum clearance and integrated objective; proposal20.944m, ideal no-world follower1,675 ticks. Not physical movement proof.
- Stage57: same actor/world/guard rules on the centered source route moved6.950011m, one goal, zero laps. One predicted underbody contact was rejected before committing movement. It is not a zero-hazard full-loop result. Exact sliver geometry, local fit and original RGB associations are retained; no face was silently relabeled.
- Stage58: isolated candidate-only mesh transport prototype. Nine authored fixtures pass; real aggregate Polycam geometry split into32 synthetic anchor tiles preserves29,366 triangles and float32 triangle coordinates; five saved native query results match monolithic geometry. This is NOT actual ARKit streaming, live hazard fusion, device performance or navigation. All physical-guidance authority remains false. Earlier defective revisions are preserved.
- iPhone integration audit: existing ARKit mesh capture does not yet feed room-scale native routing; current app planner consumes short-horizon raw-depth observations. No live app code was edited or deployed.

Read each experiment's README, frozen protocol and independent review inside the archives. Traces contain committed movement; proposal-only figures are labeled separately. Numerical body profiles are not validated participant measurements. Raw-depth and map uncertainty remain unresolved; all runs are controlled offline diagnostics.
