# First supplied-phone-map route adapter

This adapter does not construct a new map or search algorithm. It loads the exact supplied Koivu split-support occupancy-threshold-0.7 masks, with their original permissive unresolved flags, and uses the pinned Recast/Detour engine for routes. It reads only the eight phone-derived mask fields and metadata `lo`, `R`, `t`, `res`; reference arrays present in the metadata archive are never materialized by this adapter.

The game's proper coordinate convention is `[levelX, height, -levelY]`. Source cell `(i,j)` spans game Z `[-(loY+j+1)*0.05, -(loY+j)*0.05]`. The imported level rotation and translation are not refitted. Upstream quads are reflected in Z and triangle winding reversed to preserve upward normals. Route points are converted back to the upstream checker's coordinates before invoking its unchanged sampled rectangle routine.

Selection uses the source audit's seed 11, at most 60 sampled disc-clearance endpoints, endpoint feasibility over 72 headings, and pair order `a < b`. It stops at the first native route with the original 2–6 m path-length criterion and sampled rectangle fit; every prior rejected pair is retained. The native search radius is 0.375 m. The sampled rectangle includes the unchanged 0.15 m margin on every horizontal side of a 0.45 m wide by 0.30 m deep body. The true continuous swept body and reference collisions belong to the independent simulation scorer, not this sampled check.

The native query may project each endpoint by up to the original 0.1 m horizontal association bound. Consequently the recorded native path length can be slightly shorter than straight-line distance to the original commanded goal; these are different endpoint definitions, not an actor teleport. Original start and goal remain the physics commands. The adapter never snaps the actor. The returned `points` field omits the projected start once; consumers must not remove another point.

First selection: 57 pair queries, first accepted pair index 56, native path 2.0192731303570572 m, original straight-line distance 2.024845673131659 m. The initial sampled rectangle covers 219 unique map cells, of which 203 carry `lowUnresolvedFlag`. This is explicitly a permissive candidate, not sensed clearance. A far-only-dip flag is absent from the supplied artifact and is reported unavailable. No reference outcome may replace this selected route.

Seven component fixtures passed. The first bounded selector wrapper failed before map loading because the standalone script attempted to raise the inherited CPU hard limit from 60 to 65 seconds. That failure, executed source and freeze were preserved. A separate second freeze/output used 60/60 seconds, with no map, seed, route, body or threshold change; it completed in 0.63 seconds. No route-selection statistic is counted as a movement episode.
