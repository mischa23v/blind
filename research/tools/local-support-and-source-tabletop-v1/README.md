These checked compact research checkpoints preserve progress **and failures**. They do not establish autonomous phone navigation or human safety.

- **59 — conditioned floor membership:** a general one-pass triangle-quality rule adds one original floor face across five memberships; no geometry changes. The aggregate preparation output exceeded its declared5MiB target (6.34MB retained), although process limits and disk reserve passed. Genuine sub2mm ridges remain ambiguous.
- **60 — fixed-datum attempt:**13.261773m, three goals, no lap; all nine terminal rays hit known floor, but the fixed height-datum association gate rejected the next step.
- **61 — measured local support:**15.658816m, four goals, no lap; the full command was rejected before a predicted standing-table rim contact. Finite support probes and the retained residual band do not certify tiny-object detection.
- **62 — checkpoint tool:** standard-library, dry-run-by-default archive verification and explicit missing-file restoration. No network, overwrite, code execution or automatic dependency acquisition. Its seven-entry index describes earlier published packets, not these new archives.
- **63 — actual-arrival leg replanning:**15.529728m, four goals, no lap. Removing redundant anchor reconnection did not fix the missing source tabletop geometry; a second standing-table rim facet rejected the command. No rejected movement was committed.
- **64 — source-only tabletop audit:** original RGB contours plus native-depth interior fits support missing exported-mesh rim geometry. Three source views are checked; FARO is not used in this construction.
- **65 — exclusion hypothesis:** an additive source-only horizontal hull from views19/21; candidate only, unknown authority, no navigation or collider use. ±3px is a stress assumption, not a confidence bound. Frame20 was geometrically withheld from construction but previously inspected, not fresh blind validation.

## Archives and reproduction

Five deterministic ZIP groups retain all code, measured results, arrays, manifests, public diagnostic images and rejected attempts from stages59–65. `MANIFEST.json` lists each original workspace-relative path, source SHA-256, size and archive group. Every archive embeds this common manifest. `PACKAGE_METADATA.json` pins ZIP SHA-256, Git blob ID and byte count. Extract only in a controlled workspace, preserving original relative paths; never blindly overwrite divergent evidence.

These packets are **not standalone**. Large original MuSHRoom/Polycam/FARO assets, earlier pinned checkpoints, native libraries and Python dependencies are not duplicated. Experiment manifests record their dependency identities. The62tool can inspect older supported archives; adding these groups to its index requires a separately verified publication update.
