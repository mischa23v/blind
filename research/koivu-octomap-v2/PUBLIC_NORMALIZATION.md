# Public snapshot and hash semantics

This additive packet contains final native build-04 source/fixture evidence, separately identified build-01–03 history, the frozen recorded v2 fusion/import source and outputs, independent recounts/reviews and owner-produced phone-map footprint/route feasibility records. It does not contain game episodes: all 20 unavailable route slots and the requested-but-unlaunched 100 runs remain zero executed journeys. Sibling native-worker/model/selector binaries and code are not silently represented as this packet's own implementation; their retained source/result hash references are listed as external dependencies.

Original private files remain unchanged. `PUBLIC_NORMALIZATION.json` maps every copied original hash/byte count to its public counterpart. Only public copies of receipts/docs/logs can replace execution prefixes with `$WORKSPACE`, `$SHARED` or `$RUNTIME`; technical parent/child process terminology is retained. All Python/C++/header/CMake/license bytes and saved NPZ/JSON model outputs remain exact. Historical proposal/review-pending text is not rewritten as though later facts were already known.

Every embedded historical source/data/protocol/config/binary/artifact hash retains its ORIGINAL-byte referent, even if the corresponding displayed receipt has normalized paths. Use the original/public mapping to identify the public copy. Existing frozen checks may reject normalized configuration or review text; a separately approved local reproduction requires exact prerequisites and a declared matching source/configuration cut. No full clean-machine reproduction is claimed.

All three saved map NPZs (each below 8 MB), the small finalized footprint-neighbourhood NPZ, surface JSON, scan records and map receipts are included directly. The already-published 15 MB raw v1 map, 294 raw depth images, full archives and compiled libraries are intentionally omitted and identified by hash. No new download, build, fixture, native call, fusion, geometry evaluation, recount or game was executed during packaging. Validation checks only hashes, syntax, JSON and payload membership.
