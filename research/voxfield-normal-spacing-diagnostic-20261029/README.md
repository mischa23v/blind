# Normal-spacing diagnosis: exported raster evidence, not an accuracy gain

Read RESULT.md and INDEPENDENT_REVIEW.json. In three frozen training frames, all admitted unequal-depth adjacency transitions occur at one phase of a four-pixel pattern. Exact optical +Z normals total 807,230 of 1,275,637 numerically valid normals (63.2805%), matching equal-depth triplet counts. This is not a measured real-normal error rate: genuine frontoparallel surfaces can also yield +Z. It does not identify the exact exporter implementation or raw-sensor noise.

The separately controlled tilted-plane example shows a mechanism: ideal, millimetre-quantized and fourfold-repeated depth produce different angular errors. Synthetic repetition phase differs from the recorded phase and was not fitted. No provider change, mapper rerun, heldout/reference input, accuracy improvement or route/safety acceptance occurs in this checkpoint. Existing mixed geometry results and original failed resource batch remain unchanged.
