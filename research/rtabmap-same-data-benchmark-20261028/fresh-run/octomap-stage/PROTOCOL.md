# Frozen native OctoMap occupancy arm

Prepared before any occupancy data run, 2026-10-28 18:33 UTC. Released RTAB-Map 0.24.2 commit8cd2f81a735722402d1e220147c4e83a1a746eaf with official Debian OctoMap1.9.7+dfsg-4. Separate runtime build preserves previous fixed/graph mapper builds and all outputs. Same aggregate approved resources; new stage begins18:28:24, deadline19:08:24,35 CPU minutes. Interrupted first build conservatively charged180CPU seconds.

Inputs are the already frozen fixed/map.db native local grids and fixed/POSES.tsv (265 unique IDs1..265). No RGB/depth replay, classification changes, floor fit, pose optimization, FARO input, threshold tuning or room editing. Original data hash manifest and fixed mapper parameter dump retained. Database opened read-only. Every local grid must have native cell size0.04m, no precomputed empty cells and zero sensor viewpoint translation; otherwise stop rather than infer a transform.

Native LocalGridCache→OctoMap::update incrementally receives each existing node in original order and the complete prefix of unchanged poses. World frame is RTAB basis A times phone OpenGL; node pose=A*savedOpticalPose*CameraModel.opticalRotation().inverse(). This is algebraically identical to the fixed mapper's original node pose. Export transforms coordinates by B=A.inverse() once, back to original phone OpenGL coordinates. Native ground labels remain separate and are NOT verified floor support.

Parameters are the fixed mapper's dumped parameters with only Grid/RayTracing=true. Explicit unchanged relevant values: Grid/3D=true,CellSize0.04,RangeMax4,RangeMin0, GroundIsObstacle=false; GridGlobal/OccupancyThr0.5,ProbHit0.7,ProbMiss0.4,ProbClampingMin0.1192,ProbClampingMax0.971,FloodFillDepth0,Erodedfalse. Full parameters written before ingestion. Native OctoMap range clipping is its released radial rule, distinct from original axial depth cutoff. No custom ray marching or occupancy fusion.

Native fixtures precede real grids: one occupied hit; repeated farther observed endpoints clear the old cell through measured rays; missing evidence does not clear; unobserved query remains unknown; head/low obstacles stay separately occupied; ground label is distinguishable from free/obstacle; transform roundtrip and nonidentity node transform agree with analytic expected positions. Probabilities/state are asserted, not tuned until fixtures pass. Any failure blocks real replay and is preserved.

Exports: full native octree preserving probabilities where available; binary leaf records with native center,size,occupancy probability,type,reference ID and occupied flag; explicit unknown=unrepresented (never free). Free cells exported separately from occupied native obstacle and native ground. Native createCloud originalRefPoints=true produces measured-reference endpoint clouds for occupied+ground geometry, transformed once. Do not call empty cells safe floor or inferred ground safe support. Log per-frame native counts/memory/time and final category counts. No filled surface/Poisson mesh.

Evaluation is a separately pinned extension of the already verified common4cm point→unchangedFARO protocol. Compare native occupied+ground endpoint cloud as a geometry proxy; free/unknown statistics separately. Forward/reverse nearest distances are not hazard recall, traversability or navigation accuracy. No real-data output inspected to choose parameters. Native contradiction fixtures prove a mechanism, not real-world safety.

Source-review clarifications before execution: released ground endpoint insertion calls updateNode(key,true) and assigns ground type; it is not a free cell despite an older source comment. Free-ray misses can leave historical ground/obstacle type and reference ID unchanged while probability crosses below occupancy threshold. Occupied/free flag and probability are authoritative, not type/ref ID or assumed freshness. Occupied endpoints are integrated per point; free rays are deduplicated once per node with a native KeySet. Multiple transformed endpoints can share a world voxel, so hit/miss weighting is asymmetric; it is preserved and disclosed, not silently normalized.

Additional pre-run native fixtures explicitly check that cleared cells may retain historical obstacle type/refID, identical pose-prefix resubmission does not double-integrate evidence, and two endpoints in one key receive the released per-point hit weight. LocalGridMaker transforms segmented grids back into node/base frame; full original node pose is applied once. Native .ot serialization preserves occupancy/color but not custom type/refID/pointRef fields; leaf records and endpoint cloud retain those needed outputs separately. Little-endian uint64 category index files reference leaf records for occupied, free, native-ground-occupied and other-occupied subsets.
