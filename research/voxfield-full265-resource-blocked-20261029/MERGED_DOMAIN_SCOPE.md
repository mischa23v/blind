# Extension of the bounded arithmetic argument

The earlier `../prefix3-d1-n2/MERGED_DOMAIN_REVIEW.md` was admitted only for the three-record prefix. This full-run proposal does not silently reuse its admission.

Its mathematical premises concern each frame/bin: at most 733,572 points, unchanged integer-mm admission, finite positive bounded weights, proper native quaternion/rotation, translation components no larger than 16 m, fixed 4 cm/20 cm/no-clearing configuration. The new all-265 preflight checks these premises for every original record before any engine. Metadata-only preparation found a maximum translation component of 4.715816020965576 m; raw point/weight/native-transform premises still require runtime verification.

Only if all premises hold does the same source-derived conservative envelope apply per frame: total merge weight <1e12; local component magnitudes <8 m and positive axial component >0.0008 m; finite normal accumulation; transformed physical ray remains nonzero; truncation-extended world endpoint component <31 m, scaled magnitude <775, and index-count arithmetic far below limits. Full input identities and ordering are frozen separately. No pose is recentered or optimized.

This is an input-arithmetic argument, not geometry accuracy, noise reliability or complete map-history safety. Repeated-map updates are separately inspected for finite state after every frame. Any failed premise aborts the run without relaxing the 16 m domain or dropping inputs. No arbitrary future capture or native-invalid API is covered.
