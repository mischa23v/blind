# Frozen offline path-deviation diagnostic protocol

Frozen before fixture execution, 2026-10-27. This evaluator consumes supplied geometry and poses, never estimates them. It has no map writer, planner, speech, controller, or movement-authority output. The running stage84 matrix and all its frozen files are untouched.

Reuse the repository's unchanged pinned Recast/Detour `dtDistancePtSegSqr2D`, `dtVdot2D` and vector helpers through a small compiled C ABI adapter. Float geometry is intentionally the upstream representation. No new nearest-path selection, SLAM, path search or collision logic.

Inputs: explicit ordered polyline (2–256 finite XYZ metre points, one declared floor), map/frame/revision/session identifiers, capture/now in the same monotonic clock epoch, caller-declared maximum age and association radius, selected segment index and camera forward vector. Identity and units must match exactly. Coordinates are bounded to ±1000m, nondegenerate horizontal segments at least1mm, all route Y within1e-6m. Minimum length is checked both in supplied double geometry and upstream float geometry. This excludes stairs, slopes and vertical portals. Bounds are computational/domain declarations, not sensor tolerances. Metadata declares supplied-pose provenance; it is not independent measurement certification.

Axes are X/Z horizontal, Y up. Positive signed cross-track is LEFT of the directed segment: (dz*offsetX - dx*offsetZ)/length. Heading error is signed left-positive angle from segment direction to the horizontal camera-forward vector, normalized to [-pi,pi), including exact opposite=-pi. Reversing the path direction flips cross-track sign. Camera direction is not body direction; body heading is always unavailable in this module.

The caller supplies the segment; the evaluator never changes it. Unclamped projection outside[0,1] is beyond_segment, never snapped to an endpoint. Along-path distance is cumulative horizontal lengths plus projection on the selected segment. Segment-end distance, t and signed cross-track come from that same segment. Any OTHER segment within the supplied association radius creates ambiguous_segment, including repeated, overlapping, crossing and adjacent turn endpoints. This is diagnostic ambiguity, not a blocked-space determination. No nearest winner, progress jump, turn authorization or arrival claim. Outside the selected segment's declared association radius returns outside_association_radius, not a navigation decision. Valid metrics are withheld for ambiguity/invalid association; reasons and conflicting segment IDs remain available.

Reject mismatched frame/floor/map revision/session/clock, stale/future/negative/nonfinite times, missing source provenance, invalid geometry/radius/age, noninteger/out-of-range segment, and nonfinite pose/forward. A finite camera-forward vector is normalized in double before float conversion. A nearly vertical or zero camera-forward vector leaves camera-heading unavailable while position metrics may remain available. No vertical pose-to-ground inference occurs. The projected metrics intentionally ignore pose Y; same floor identity is supplied, not independently verified.

Fixtures are synthetic analytic cases, not real localization accuracy. Cover both cross-track signs, reversal, all cardinal directions, heading wrap, turns and cumulative progress, before/after segment, zero/vertical/short segments, overlaps, crossings, nearby parallel paths, large-coordinate limits, stale/future/frame/clock/revision/session errors, nonfinite/bool types, heading unavailable, input immutability, and literal no-authority output. Freeze hashes before running. Compile only the tiny adapter and unchanged upstream common/allocation/assert translation units, serial, maximum120s wall/60s CPU/512MiB address-space; test maximum30s wall. No installs or downloaded files, no native app job or real-data replay. Record failures without replacing them by later passes.

Review clarification before second execution: distance outputs are upstream float32; the supplied radius remains a double policy value, compared without an invented tolerance. A mathematically equal decimal boundary can therefore reject (e.g.0.1m), and classification inside float quantization is not established physical precision. Conflicting nearby segment IDs remain recorded even if the selected association is outside/beyond. Compiler timeout signals only its newly owned process group; CPU limits are per-process, not aggregate, and no escaped-child containment claim is made. Interrupted evidence filenames are never reused.
