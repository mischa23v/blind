# CPU and UI identity evidence-only integration

Combines the independently reviewed optional DEBUG worker CPU diagnostic with the independently reviewed identity-only UI result inspection. Current baseline is ceaaa1c1. Existing test results remain unchanged historical evidence.

The UI increment captures bounded installed xcresulttool test-details help/schema and metadata for exactly the synthetic Practice and Ask tests, together with the selected preflight simulator identity. It does not inspect simulator sandboxes, select another device/container, change the Practice exporter, activate an Ask observer, suppress an audit or retry failed tests.

The CPU-only manifest remains a frozen earlier review. Its SOURCE_PINS entry is superseded here only to bind the reviewed workflow change and two new identity tools; the CPU source and reverse helper layer are unchanged. Public/ref guards and pinned actions remain. No metadata implies a test pass or physical clearance.
