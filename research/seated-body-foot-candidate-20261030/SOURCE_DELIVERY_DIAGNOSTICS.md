# Second Apple failure: source delivery is unmeasured, not a proven geometry defect

At published source `b55cf93428cc70f3b470a2a61e88a94044f19c2b`, the classified package passed all 65 tests. Both added hosted seated cases failed their initial scene predicate before any route query was submitted. `submittedStart` was nil, route clocks were -1 and route worker records absent. These are source/display-admission failures, not failed paths or successful movement. Both teardown waits also expired. The original Apple failure remains evidence.

The first owner recorded discard release at 29,885 ms and utility completion entry at 63,059 ms: 33,174 ms after release. The second owner waited 18,572 ms from discard request to worker entry. This demonstrates scheduling delay outside native storage release but does not establish its cause. In particular, no evidence establishes a MainActor deadlock, geometry corruption or cold native computation. Existing async XCTest fulfillment is not a synchronous main-thread wait; backend main dispatch matches production. Decoder FIFO orders owner ingestion before source requests, but the prior diagnostic phases did not cover source-copy worker and delivery.

This patch adds opt-in DEBUG source enqueue, worker begin/end and delivery begin/end to the existing bounded runtime receipts. The synthetic controller fixture adds bounded source-native-callback/main-callback/controller/render-enqueue/render-begin/render-end/display/refusal events, elapsed from each source request and including only an is-main-thread flag. Runtime stages retain their owner-relative clock: subtract matching stage pairs, never treat owner elapsed as queue latency. Renderer begin is queue execution, not enqueue. Missing stages remain unknown. No camera, geometry, source IDs or private data are logged; only random diagnostic receipt IDs join records.

After the unchanged ten-second source expectation, the fixture now unwraps the scene before submitting any route. A missing scene remains a failed test and always enters the same awaited ten-second drain; it no longer adds a futile route wait after source failure. Existing route assertions, strict native endpoint admission, source revision gates, QoS, policies and runtime lifecycles are unchanged. The metadata does not fix the unknown source delay or prove a passing integration.

The new reversible layer preserves b55 and earlier source/failure layers exactly. No native execution for this patch has occurred. Extractor/parser checks and hash reversals are source-only evidence; root owns actual Apple rerun/publication.
