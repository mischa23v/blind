# Proposed additive occupied-only veto seam — not active wiring

Keep `MeshCandidateRoute.rawDepthHazardImplemented=false` until end-to-end tests. Do not merely flip its constant. Add a separate optional candidate-diagnostic result alongside the unchanged route. No new camera owner or speech/guidance sink.

Proposed types, to be implemented/tested at the existing owned ingress boundary:

- `FreshDepthObstacleBatch`: immutable `sessionID`, coordinate frame identity, capture sequence + original capture uptime, depth/intrinsics policy digest, full camera transform, source confidence availability/admission rule, actual occupied-cell/point evidence, coverage/truncation, and recorded geometric uncertainty. ARKit live confidence-2 admission must be explicit; processed Coffee data cannot construct this live-authority type. A cell's full bounds and uncertainty must be preserved, not just center points.
- `MeshDepthVetoRequest`: exact mesh route generation/revision, candidate points, batch identity, body/profile revision and full envelope, current time, validated frame transform binding. Never infer identity because both arrays are numeric XYZ. No ad-hoc yaw transform.
- `MeshDepthVetoReceipt`: `blockedByObservedIntersection`, `noObservedIntersectionNotClearance`, or `unavailable(reason)`, carrying the unchanged owned identities. All outcomes permanently have `authorizesPhysicalGuidance=false`. A no-intersection result cannot open a route, grant support, set world-coverage true, or override another veto. Unavailable cannot be treated as pass.

The production intersection must reuse the selected existing swept-body/collision implementation, not a new point-distance heuristic. A valid fresh occupied intersection may only remove a candidate. Unknown extent, missing confidence, stale/future frame, wrong session, expired map transform, invalid body envelope, missing uncertainty or truncation return unavailable. Do not fabricate zero uncertainty to make it run. Existing independent HazardDetector / BodyCollisionWarning remain ahead of this asynchronous work.

One bounded worker; no raw AR buffers escape their owner; drop busy work rather than growing a queue. Every capture/mesh/body/transform/goal revision change invalidates queued results, and delivery rechecks all identities and age. Occupied-only integration does not grant permission to ray-clear prior obstacles. Future removal requires separately reviewed fresh positive free-ray evidence and dynamic-object policy; missing detection/occlusion never clears.

Prepared acceptance controls: table present in depth but absent from mesh blocks a registered intersecting candidate; corner intersects cell/body bounds despite clear centerline; table above floor is retained; missing confidence/unregistered frame/expired capture returns unavailable; replacing route/body after enqueue retires result; no observed intersection never changes physical authority; native/worker failure cannot erase an existing blocker. These controls remain unexecuted. The current three-frame processed data can exercise historical source retention but cannot satisfy this live batch's confidence/frame/uncertainty requirements.
