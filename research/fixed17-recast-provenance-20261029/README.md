# Fixed-cell Recast provenance: public preservation record

## What was established

One guarded, serial experiment compared two frozen reconstructed meshes at17 preregistered native columns. It preserved the original20 route records and678 witness records per model as immutable controls, without recomputing routes/witnesses or loading reference geometry.

All mandatory parity gates passed: reconstructed null/non-null heightfield layers, native compact heights/links, original-versus-observed-versus-saved erosion areas, native distance/seed ancestry, and ordered-union raw raster columns. Existing saved ancestry controls also matched. Synthetic observer fixtures passed. The run used2.79928 aggregate CPU seconds and2.82973 wall seconds, with206,610,432bytes conservative peak aggregate RSS and4,812,722bytes output, including its small native compile. Aggregate limits and results are retained in `AGGREGATE_RECEIPT.json`.

The principal tested lower-geometry gap was present in the frozen source/native representation before merging, ledge filtering and erosion: the conservative candidate superset contained only upper geometry there, and native rasterization produced no lower contributor. Separate tested initial-null blockers had only slope-rejected lower contributors. Mixed null/walkable neighboring contributors merged correctly. Native chamfer seed ancestry matched the saved predictions.

**This does not establish physical absence of floor, explain capture/occlusion/fusion causes, prove clearance, repair any route or admit navigation.** No radius, slope, climb, grid or map changes were made. The result narrows investigation toward upstream source coverage and facet quality; it does not authorize filling holes, flattening geometry or relaxing acceptance criteria. The independent exact-grid-clearance defect is a separate question.

## Exact sources versus export variants

`SOURCE_MAP.json` explicitly distinguishes:

- Exact preserved bytes: isolated renamed released erosion body, observer header, exact body diff, and project-owned VTK reader glue. Exact means identical to the source used in the completed experiment—not that all files are unmodified upstream code. The erosion body is clearly marked as an altered observer version.
- **Unexecuted export variants:** shim, worker and synthetic-fixture source with dataset-bound placement/bounds/cells externalized. The worker also removes private admission/compiler launch logic and refuses execution unconditionally. Export hashes differ from their original-source hashes. They have not been compiled or run and inherit no runtime validation verdict.

`private_fixture_config.h` / `private_fixture_config.py` are intentionally absent. The source text describes the expected fields, but no actual values are distributed. Export scripts are inspection aids, **not standalone reproducibility**. The packet does not include a runnable experiment, dataset access rights, original runtime/toolchain, native library binary, frozen geometry/control arrays or execution authority. Hashes identify private originals; hashes cannot reproduce missing inputs.

The original guarded run included one-CPU enforcement, aggregate CPU/wall/output limits, sampled aggregate RSS with conservative reaped-child accounting, pre/post source/input hashes, compiler identity checks and no retry. The public packet preserves those aggregate facts, not the private launch authorization. RSS was observed/guard-enforced, not a hard kernel RSS limit. The original sysroot/transitive runtime were not fully byte-pinned.

## Contents and exclusions

Only files on the reviewed publication whitelist may be published. No meshes; real triangle, span, ray or trajectory arrays; actual vertices/cell coordinates/bounds; compiler binaries; admission token/content/digest; or geometry-bearing source receipts are included. Synthetic square/multilayer values retained in the fixture export are authored test data, not captured geometry. Code variable names and routines that would process arrays are source text, not dataset arrays.

The permitted receipt hashes identify the original guard receipt, source freeze, aggregate summary and fixture receipt. The original guard receipt itself is **not** redistributed because it contains private launch details. No actual admission digest is included.
