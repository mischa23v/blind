Local, unpublished preservation packet. No inference, synthetic test, imports of
diagnostic modules, PNG decoding, dataset archive reading, or extraction was
performed to assemble this packet. Only existing authored text and saved JSON
results were read. Exact source copies retain their original SHA-256 identities.

Observed result: original F=diag(1,-1,-1) was inconclusive. The subsequent frozen
24-convention search selected identity C and 0.001 metres/stored-unit as an
INFERRED, CONDITIONAL export hypothesis that survived the declared internal
checks. Four development pairs and two heldout pairs were used. Read the saved
aggregate JSON for losses, competing-convention gap, stability and controls.

This is NOT author-documented encoding, an independently calibrated unit, metric
mapping accuracy, stair-detector accuracy, or evidence of navigation safety.

remain assumptions. RGB/video synchronization is unresolved. Near-minimum scale
ranges are heuristic profile ranges, NOT statistical confidence intervals.

Contents: byte-exact authored Python sources and plan text, sanitized provenance,
aggregate diagnostic and synthetic statuses, sanitized resource receipts, and a
file hash manifest. Historical plan text intentionally preserves its original
pre-execution wording; the aggregate result files record the later outcomes.

Excluded: raw CSVs, per-frame poses, pair manifests/IDs, PNG/RGB/depth/confidence
samples, masks, videos, PLYs, dataset archives, and complete result/profile dumps.
