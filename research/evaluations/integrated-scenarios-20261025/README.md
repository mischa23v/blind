## Evidence and provenance

`RECEIPT_INDEX.json` hashes every compressed receipt individually. `PUBLICATION_MANIFEST.json` hashes the publication files and lists exclusions. `EXECUTION_SUMMARY.json` deduplicates sequence IDs across reruns and explicitly labels partial scope. Each episode trace records authored utterances, actual module calls/state/results, source identities and time when applicable. LLM output absent from a run is NOT RUN. The few old records with SEE_XCTEST_ASSERTIONS are not silently promoted to successful full episodes.

All user utterances, motion/obstacle/floor transformations, RGB color values, OCR strings, family identities/scores and manual text snippets in these harnesses are authored plumbing. They are not recordings from real children, verified people, measured rooms or certified localization. Real UUIDs here are freshly generated test ownership IDs, not personal identities.

The external Autodesk OAS example was decoded as an authored preview-only plan. Its source bytes are not included. It has no registered route map, body pose, live collision observation or calibration. ARKitScenes assets were inventoried separately but not replayed as calibrated native localization. Never attach ARKitScenes images/LiDAR to the OAS plan or another invented room. Obtain any external dataset separately under its terms and provide its original matching metadata. ## Independence and limitations

The deterministic seed split partitions public authored fixtures only; it is not an independent real-world held-out test set. Fixtures and assertions were visible during implementation. Frontier evaluation used a fresh agent with only the public interface, but was limited to four fixed authored text episodes. No statistical accuracy or device safety estimate is warranted.

Four benign-refusal model candidates were rejected by the production guard in the frontier run; later text was accepted. Native code-owned unavailable rendering was not executed by that harness, so the trace does not establish native silence or a model retry count. Its original state audit remains 14 PASS / 1 FAIL: resume activated correctly before an unavailable adapter changed the final state. Historical backpack evidence was explicitly retrieved and delivered. Background cancellation was ignored by model choice, not an attempted unauthorized dispatch rejected by code. Named wrong-item completion, stale output-token attempts and expired-clock dispatch were absent from those four episodes. Native speaker identity, audio delivery, camera perception, calibrated wearer pose, physical mobility, Apple runtime and device performance remain untested by this package.
