# RTAB iOS depth-confidence trace — source audit, 2026-10-26

## Finding

**Confidence is preserved as a separate image, but the current RTAB local-grid producer does not apply the hazard sampler's original-confidence-2 rule.** The renderer's high-confidence setting is a different consumer and must not be credited to ground/obstacle/empty cells. This is a source-policy divergence, **not a measured device failure** or an executed RTAB result. Retained maps remain **historical references, not live clearance**; current sensor evidence must establish any present physical claim.

Scope: app [`c8aa872748aded3bd6672c7d2e299eec5361cb94`](https://github.com/mischa23v/blind/tree/c8aa872748aded3bd6672c7d2e299eec5361cb94), pinned RTAB [`a4e7f13522722878dea3f07e8fd082291e72eb49`](https://github.com/introlab/rtabmap/tree/a4e7f13522722878dea3f07e8fd082291e72eb49). No code edits, builds, new tests, raw recordings, dependency acquisition or native reruns were performed for this audit. The native compile follow-on remains paused while phone-sensor feasibility (Gate 0) is evaluated; the first hosted attempt stopped before archive/core/app build.

## Actual data path

1. **Hazard lane, distinct from mapping.** `DepthSampler.observation` requires a confidence map, matching dimensions/formats, successful pixel-buffer locks and row-stride-aware reads. Its shared policy accepts only original UInt8 confidence **2**, depth **0.15–5m**, stride **2**. The separate `worldPoint` lookup accepts confidence >=1 and must not be confused with hazard admission. [DepthSampler.swift lines 21–38, 52–85](https://github.com/mischa23v/blind/blob/c8aa872748aded3bd6672c7d2e299eec5361cb94/ios/BlindAssist/DepthSampler.swift#L52-L85), [NativeDepthObservationPolicy.swift lines 3–27](https://github.com/mischa23v/blind/blob/c8aa872748aded3bd6672c7d2e299eec5361cb94/BlindCore/Sources/BlindCore/NativeDepthObservationPolicy.swift#L3-L27).

2. **Mapping does not consume those filtered hazard samples.** `NativeMapping.consume` admits normal tracking/fresh original frames, then passes the original `ARFrame` into RTAB. Its configured grid lane is RGB-D, 3D, **0.1m cells**, depth decimation **4**, range **0.2–6m**; 3D ray tracing is enabled only if the compiled engine reports OctoMap support. It does not configure a grid confidence threshold. [NativeMapping.swift lines 118–127, 172–187](https://github.com/mischa23v/blind/blob/c8aa872748aded3bd6672c7d2e299eec5361cb94/ios/BlindAssist/NativeMapping.swift#L118-L127).

3. **RTAB iOS preserves the optional confidence buffer.** Its Swift adapter takes `frame.sceneDepth?.depthMap` and `.confidenceMap`, locks/passes pointers, sizes, dimensions and pixel formats. In C++, Float32 depth is cloned; a matching OneComponent8 confidence map is rescaled **0/1/2 → 0/50/100**. Depth is not zero-masked by confidence here. Missing/wrong-format confidence leaves an empty confidence matrix while depth can still proceed. The iOS wrapper supplies null depth extrinsics/zero depth intrinsics, so the separate RGB/depth-registration branch is not an additional iOS confidence filter. [RTABMap.swift lines 270–336, 356–388](https://github.com/introlab/rtabmap/blob/a4e7f13522722878dea3f07e8fd082291e72eb49/app/ios/RTABMapApp/RTABMap.swift#L270-L336), [RTABMapApp.cpp lines 4641–4660, 4696, 4784](https://github.com/introlab/rtabmap/blob/a4e7f13522722878dea3f07e8fd082291e72eb49/app/android/jni/RTABMapApp.cpp#L4641-L4660), [NativeWrapper.cpp lines 302–309](https://github.com/introlab/rtabmap/blob/a4e7f13522722878dea3f07e8fd082291e72eb49/app/ios/RTABMapApp/NativeWrapper.cpp#L302-L309).

4. **Camera/Memory carry the two images separately.** `CameraMobile` rotates depth and confidence together, preserving alignment in its orientation branch. The app starts an ordinary `SensorCaptureThread(camera_)`; its optional bilateral filter defaults off. Memory copies the confidence image into the signature, then invokes the local-grid maker. No original-confidence-2 mask is installed along this configured path. [CameraMobile.cpp lines 418–446](https://github.com/introlab/rtabmap/blob/a4e7f13522722878dea3f07e8fd082291e72eb49/app/android/jni/CameraMobile.cpp#L418-L446), [RTABMapApp.cpp lines 1052–1056](https://github.com/introlab/rtabmap/blob/a4e7f13522722878dea3f07e8fd082291e72eb49/app/android/jni/RTABMapApp.cpp#L1052-L1056), [SensorCaptureThread.cpp lines 120–139](https://github.com/introlab/rtabmap/blob/a4e7f13522722878dea3f07e8fd082291e72eb49/corelib/src/SensorCaptureThread.cpp#L120-L139), [Memory.cpp lines 6379–6382, 6885–6887, 6933–6944](https://github.com/introlab/rtabmap/blob/a4e7f13522722878dea3f07e8fd082291e72eb49/corelib/src/Memory.cpp#L6933-L6944).

5. **Decisive grid call: confidence threshold is zero.** `LocalGridMaker` calls `cloudRGBFromSensorData` with arguments ending at `roiRatios_`; the omitted final `confidenceThr` defaults to **0**. The utility only selects the confidence image when threshold >0, and explicitly uses an empty confidence matrix for threshold0. Projection therefore keeps finite in-range depth regardless of its original low/medium/high confidence value. This is not completely unfiltered geometry—range, decimation and later geometric segmentation still apply—but it is **not confidence-filtered grid geometry**. [LocalGridMaker.cpp lines 296–310](https://github.com/introlab/rtabmap/blob/a4e7f13522722878dea3f07e8fd082291e72eb49/corelib/src/LocalGridMaker.cpp#L296-L310), [util3d.h lines 601–609](https://github.com/introlab/rtabmap/blob/a4e7f13522722878dea3f07e8fd082291e72eb49/corelib/include/rtabmap/core/util3d.h#L601-L609), [util3d.cpp lines 1163–1165, 485, 579–592](https://github.com/introlab/rtabmap/blob/a4e7f13522722878dea3f07e8fd082291e72eb49/corelib/src/util3d.cpp#L1163-L1165).

## What ground and empty cells mean here

**Missing depth is a different case from missing confidence.** Upstream may retain a feature-point scan when scene depth is absent, but the app selects `Grid/Sensor=1`; Memory requires a depth image for that grid path. Feature points do not silently become the configured RGB-D ground/empty grid. [RTABMapApp.cpp lines 4762–4784](https://github.com/introlab/rtabmap/blob/a4e7f13522722878dea3f07e8fd082291e72eb49/app/android/jni/RTABMapApp.cpp#L4762-L4784), [Memory.cpp lines 6933–6944](https://github.com/introlab/rtabmap/blob/a4e7f13522722878dea3f07e8fd082291e72eb49/corelib/src/Memory.cpp#L6933-L6944).

- Ground/obstacle labels follow pose-based roll/pitch rotation, voxel filtering and normal/cluster segmentation. Defaults include normal segmentation on, max ground angle45°, 20-neighbor normals, 0.1m cluster radius and minimum cluster size10; generic height cutoffs are disabled at zero. These parameters classify geometry; they do not measure navigable support, obstacle recall, human clearance or floor-height uncertainty. [LocalMapMaker.hpp lines 94–131, 153–185](https://github.com/introlab/rtabmap/blob/a4e7f13522722878dea3f07e8fd082291e72eb49/corelib/include/rtabmap/core/impl/LocalMapMaker.hpp#L94-L185), [Parameters.h lines 915–940](https://github.com/introlab/rtabmap/blob/a4e7f13522722878dea3f07e8fd082291e72eb49/corelib/include/rtabmap/core/Parameters.h#L915-L940).
- With compiled OctoMap and ray tracing enabled, empty cells come from rays through the same classified ground/obstacle cloud and the camera-model viewpoint. They are not a separate higher-quality sensor measurement. Without that capability the configured 3D path has no generated empty-ray class; absence is not free space. [LocalGridMaker.cpp lines 514–564](https://github.com/introlab/rtabmap/blob/a4e7f13522722878dea3f07e8fd082291e72eb49/corelib/src/LocalGridMaker.cpp#L514-L564).
- The app bridge copies XYZ classes/counts/truncation, original capture association and corrected poses—not per-cell source confidence, confidence coverage, depth variance or a supported terrain interval. The consumer's 0.5s current-pose lease and 30s history retention are ownership/age rules, not accuracy or dynamic-clearance guarantees; physical guidance remains false. [Bridge payload lines 10–28](https://github.com/mischa23v/blind/blob/c8aa872748aded3bd6672c7d2e299eec5361cb94/integration/rtabmap/BlindLocalGridBridge.hpp#L10-L28), [NativeLocalGrid.swift lines 75–95, 124–134](https://github.com/mischa23v/blind/blob/c8aa872748aded3bd6672c7d2e299eec5361cb94/BlindCore/Sources/BlindCore/NativeLocalGrid.swift#L75-L95).

## Unresolved quality gates relevant to phone feasibility

1. Original confidence availability/coverage and the actual confidence admission policy must be distinguished for each lane. A denser RTAB map is not proof of improved reliable coverage when it admits low/medium-confidence depth.
2. Depth/intrinsic error bounds, thin/near/overhead obstacle misses, temporal motion/occlusion and negative-space/drop-off observability are not established by those grid labels. Cell size is not a metric sensor-error bound.
3. The upstream adapter assumes packed depth/confidence rows (`cv::Mat` without explicit row step); it does not carry CVPixelBuffer bytes-per-row through that C interface, unlike the hazard sampler. This is a source assumption requiring format/stride validation, not an observed corruption claim.
4. Tracking-normal admission and corrected SLAM poses do not supply calibrated physical uncertainty. `CameraMobile` creates heuristic diagonal odometry covariance (first-frame/ordinary/bad-tracking multipliers), not measured error. It must not become a validated localization bound. [CameraMobile.cpp lines 543–569](https://github.com/introlab/rtabmap/blob/a4e7f13522722878dea3f07e8fd082291e72eb49/app/android/jni/CameraMobile.cpp#L543-L569).
5. Body/belt/phone extrinsics, mounting changes, full-body/equipment envelope, trustworthy ground support and an independently evaluated route corridor remain separate requirements. Confidence and a ground/empty label do not satisfy them.

**Implication:** Gate 0 must measure the actual admitted sensor coverage and misses for the intended mounted-phone/body configuration. Neither display clouds, grid counts nor synthetic navigation can substitute for that evidence. This audit identifies a real policy divergence; it does not claim a new physical test failure or justify changing any threshold without review.
