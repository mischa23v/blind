## Result first

**Normal app depth warnings exist independently of a mesh. Mesh-route previews do not consume that depth as a route obstacle overlay.** `rawDepthHazardImplemented=false` is a truthful mesh-candidate limitation, not proof that the entire app lacks depth warnings. In deliberate seated mesh diagnostics the normal warning loop is explicitly unavailable. The best next geometry step is to retain measured tabletop/overhang endpoints through a proven occupancy producer and bind those obstacles to route rejection; tuning body radius against an incomplete mesh cannot recover an absent table.

The user visually rejected the longest Coffee route for clipping a table corner. Retain the historical 20 native proposals as historical integration results, **not 20 real-use accepted paths**. This user review is not an independently measured collision or a new metric ground-truth annotation. The 6.19 m route remains rejected for real use; measured corner/route correspondence is still required to quantify the defect.

## Reuse first: smallest supported direction

1. **Keep the original mesh unchanged.** Add a separately identified, occupied-only measured-obstacle layer/candidate veto; do not manufacture a tabletop polygon, floor fill, inferred legs, or free volume. Tabletop overhang matters throughout the body-height band, not only floor-contact geometry. A cell/blocker's full bounds matter; its center alone is insufficient at a corner.
2. **For phone source integration, reuse the already published RTAB local-grid bridge**, not new SLAM/raycasting: RTAB `a4e7f13522722878dea3f07e8fd082291e72eb49`, BSD-3-Clause; `integration/rtabmap/local-grid-manifest.json` pins five upstream pre/postimages. `SensorData.gridObstacleCellsRaw()/gridGroundCellsRaw()/gridEmptyCellsRaw()` are the producer seam. `research/evaluations/rtab-local-grid/README.md` records 20 Swift checks plus C++ helper/contract checks; these are historical bridge checks, not current native execution or obstacle recall. The older `research/evaluations/observed-scene/rtab-next.md` claim that occupancy is never enabled is superseded by current NativeMapping configuration.
3. **Do not assume RTAB obstacle labels preserve all tabletops.** Existing `research/evaluations/rtab-confidence-policy/README.md` establishes that LocalGridMaker omits the positive confidence threshold and does not apply the hazard lane's original-confidence-2 policy. Grid segmentation/classification can differ from raw hits. Bridge cells lack per-cell confidence/uncertainty. First compare retained raw endpoints against each produced class, including ground; a table labeled ground must not become navigable floor. Record dropped/filtered/merged endpoints and reasons, not only final mesh triangles. Upstream packed row-stride assumptions remain unverified on device.
4. **For a bounded recorded-data comparator, reuse the already published OctoMap adapter, not Nav2/ROS installation or a new voxel engine:** `research/koivu-octomap-v2/workspaces/blind-octomap-reuse-08/ADAPTER_PROTOCOL.md`, `octomap_adapter.cpp`, `octomap_engine.py`; upstream v1.10.0, commit `007a0b5b6e4d3bb6c54f2c65a12234e03adcd72f`, New BSD. Important: implemented adapter does NOT use the earlier proposal's `discretize=true`; it retains the first actual measured point per native key, invokes native `computeUpdate`, checks exact occupied-key equality, and applies upstream free-then-hit updates. Preserve raw hit/conflict history alongside probability leaves. Existing build-04 receipt records success, not availability of that binary here. No binary/import/build was attempted by this audit.
5. **Missing adapter contract:** a route query/veto must jointly own original capture, sensor policy/config, world frame/session, map/node corrected-pose revision, route revision, full body envelope and measured uncertainty. Reject unavailable/truncated/mismatched/stale input. RTAB node-local Z-up is not ARKit-world Y-up; use full original transform chain once, never yaw-only or a guessed fixed alignment. Revalidate at delivery. Lack of occupied hits is unknown, not clearance. Keep independent urgent warnings first and asynchronous bounded geometry work afterward.
6. **Use existing route and swept-body checker machinery**, after registration. Keep table-cell/overhang collision separate from support verification. A safe-side reroute must also satisfy unchanged observed-floor support and full swept-body envelope; otherwise return blocked/unknown. No manually shifted route or new search algorithm. This audit proposes the connection, not a battle-tested adapter or physical release.

OctoMap's upstream description explicitly separates occupied, free and unknown space: <https://octomap.github.io/>. Nav2's published `nav2_costmap_2d/plugins/voxel_layer.cpp` is a secondary architecture reference (<https://github.com/ros-navigation/navigation2/blob/main/nav2_costmap_2d/plugins/voxel_layer.cpp>), not selected code: the already pinned local RTAB/OctoMap pieces are the narrower reuse. No Nav2 version/license/integration acceptance is claimed.
