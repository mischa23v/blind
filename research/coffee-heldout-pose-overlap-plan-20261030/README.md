## Preregistered pose/frustum rule

The rule was sent to root before applying it to the metadata. It uses original pose JSON SHA256 `46c8d1fc5188d38179e88eff98fd42f99956fb93b570bd9483e6e92764ae7010` and the unchanged validated camera convention `T @ diag(1,-1,-1,1)`.

1. Anchors, in fixed order, are the earliest and latest construction frames: **00290, 00391**. The middle construction frame remains in the training map.
2. Candidate frames must be at least **eight original metadata indices** from every construction frame and any previously selected holdout. This is a preregistered partition-spacing choice, not elapsed time, sensor decorrelation proof, or an accuracy threshold.
3. For each camera, form 75 **virtual**, not measured, world points: the 5×5 original image fractions `{0.1,0.3,0.5,0.7,0.9}` of `(w−1,h−1)` at axial distances `{1,2,3}` metres. These are pose/K frustum probes only. Use the exact inverse of each validated R when projecting into the other view; no image or depth byte, semantic region, occupied map, or residual enters selection.
4. Count anchor probes projected inside the candidate and candidate probes inside the anchor, using `0 <= u < w`, `0 <= v < h`, `0 < axial z < 4 m`. Rank candidates lexicographically by largest minimum directional count, largest total count, smallest optical-axis angle, smallest translation distance, then lower original index. Select one for each anchor. No hand-adjusted weights, post-result substitutes, or pose fitting.

## Proposed bounded implementation

1. **Inputs before native loading.** Verify all source/selection/archive bindings and five original per-frame pose/K contracts. From the already retained Coffee archive (`591672a1c4afa50e5109fc78ff08d8f608d05756a9181cfdd7cef38a57a1623d`, 183,080,957 bytes), extract only the two exact depth members into a new local directory, reusing the existing safe streaming extraction pattern. Reject links, duplicates, path traversal, missing members, files above 1 MiB, or more than 2 MiB total. No images, network, models, install, or whole-archive extraction. Hash original archive before/after and each extracted file. Do not replace a failing/missing view.
2. **Recreate only the original training map.** Reuse pinned projection and `T_original @ diag(1,-1,-1,1)` with each original translation as sensor origin. The official [MuSHRoom converter](https://github.com/TUTvision/MuSHRoom/blob/3f36dbfe24c783f85e320a613096eee5216839eb/iphone_tools/1_nerfstudio_to_sdfstudio_within.py) supplies this convention. Original axial depth /1000, strict `0 < z < 4 m`, full 738×994 rasters, resolution .05 and unchanged hit/miss thresholds. No pose adjustment, floor fit/filter, registration, or new annotations. Bind the recreated map to the saved baseline by exact uncompressed exported NPY payload hashes and training receipts before evaluating held-out frames. A mismatch stops the experiment rather than changing the baseline or loosening a tolerance.
3. **Read-only endpoint coverage.** Project each held-out full accepted raster using its own original K and supplied pose, then use existing `keys`/`query_keys`. Count pixel-weighted and distinct-key-weighted known-occupied, known-not-occupied, and unknown endpoints, plus prior hit/free conflicts. Preserve zero/range-excluded counts in the full-raster denominator. These queries alone establish no ray visibility or metric surface distance.
4. **Read-only fixed-grid ray residuals.** Use original image pixels `u % 8 == 0 && v % 8 == 0`, then apply the same valid-depth rule: at most 11,625 candidates per frame, 23,250 total, in batches of 256. No ROI, random redraw, replacement, densification of favorable views, or frame-dependent stride. Use the direction `R * [(u-cx)/fx, (v-cy)/fy, 1]` from the held-out origin. `maxRange = 4 * norm(direction)` preserves the original axial 4 m envelope; do not cast indefinitely or truncate to the measured endpoint, which would censor positive residuals.
5. **Never conceal unknown stops.** Precheck origin occupancy and bounded/finite nonzero ray inputs. Distinguish origin unknown, origin occupied, occupied hit after a known prefix, unknown stop, max-range stop, bounds/input error, failed voxel intersection, and unresolved native failure. Official `castRay` returns false for several reasons: its end-center range check precedes terminal-node lookup, so classify max-range before treating a terminal missing node as unknown. Validate coordinates in advance; unexpected ambiguous false returns remain unresolved, never “clear.” Initialize every output buffer/status before any native call; never inspect an uninitialized endpoint on an error. Only occupied hits reached through known space from a known-not-occupied origin are eligible for residuals. No `ignoreUnknownCells=true` fallback.
6. **Metric outputs without invented accuracy cutoffs.** For eligible rays, use upstream `getRayIntersection` and the inverse of the **same** camera transform to recover predicted axial depth. Report signed `predicted_z − measured_z` and absolute residuals in metres, plus Euclidean along-ray residual separately. Do not compare axial depth with distance to a voxel center. Publish count, min, p05, p25, median, p75, p95, max, mean, and RMS per frame; quantiles use a declared deterministic method. Include every valid scored residual, without outlier clipping or treating unscored rays as zeros. Explain the 5 cm occupied-voxel entry-face discretization; do not call it sensor accuracy or subtract a guessed tolerance. This is directed view-to-map consistency, not symmetric whole-room completeness.
7. **Prove evaluator non-mutation.** Before and after each held-out frame, compare native scan counter/evidence, tree/leaf count, defaults, and canonical exported payload hashes. Holdouts must never reach `insert`, `updateNode`, clamping/threshold changes, or mapper selection. Keep original leaf artifact and receipts untouched.
