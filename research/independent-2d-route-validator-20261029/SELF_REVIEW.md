# Pre-execution self-review

Frozen scope: one serial offline Python unittest process; no install, networking, API, C++ compilation, live guidance or route search. System GEOS via ctypes supplies all polygon validity, containment, boundary and distance predicates. Geometry destruction/context disposal are explicit. GEOS predicate failure is not a pass. Polygon validity and finite/bounded metric coordinates are checked. Zero-length segments become points. Whole-body sweep uses orientation-independent enclosing disk, half-diagonal sqrt(.45²+.30²)/2 once, then .15 m margin separately. No rounded-buffer approximation. Boundary/obstacle contact distance <= radius + 1e-8 m rejects; 1e-8 is a declared floating-point guard, not a certified precision bound. The conservative disk can reject a feasible orientation-specific rectangle route.

Full-body coverage is tested by center segment containment and boundary distance > the identical sweep radius + guard. Floor/body/head provenance, frame, revision and replay time gates remain independent. Unknown coverage never passes. Only explicit authored fixtures can receive the narrowly named clear status; every result forbids live guidance. Manual diagnostic rectangles are not measured tables and cannot yield clear. Missing real mesh cannot be repaired here. Detours are external proposals, needing revalidation in 2D and the existing 3D engine.

Authored cases include line crossing, body-only and margin-only contacts, exact/near contact, corner contact, endpoint collision, coverage gap, stale/future frame, revision mismatch, missing layers, manual diagnostics, head obstacle, invalid input and explicit longer authored detour. This is adapter testing, not an upstream GEOS suite, physical room validation, or phone/device validation.

Admission: parent specifically authorized one small portable suite under 10 CPU seconds / 20 wall seconds / 512 MiB / one worker after this review. Source and fixture hashes are frozen before that run. Failures require a new frozen attempt rather than silently relabelling historical results.
